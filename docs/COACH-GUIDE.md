# How the coach logs a referral

1. Open the Lunch Leaderboard Sheet in the Google Sheets app and tap the **Log** tab.
2. Tap the first empty row and enter today's date in **Date**.
3. In **Code**, pick the code of the member who brought the friend. Column E shows their nickname, so check it is the right person.
4. In **Event**, pick **Trial** when the friend takes a trial class (1 point).
5. When that friend signs up, add a second row with the same code and **Event = Signup** (2 more points, so 3 in total).
6. Made a mistake? Fix or delete that row. Points come only from the Log, so the board corrects itself within about a minute.
7. Only ever edit the **Log** tab. Members and Board are locked on purpose.
8. The **Private note** column is optional and is never shown on the public page.
